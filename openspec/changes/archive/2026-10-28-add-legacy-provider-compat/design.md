# Exact compatibility contract

## Minimal design
Keep the current single provider object and Object.freeze(provider), EIP-6963 detail identity and same exact-origin/main-frame injection. No facade, Proxy, mutable provider, feature toggle, new dependency, generic method dispatch or alternate approval state machine.

Before freezing, define an own non-enumerable, non-configurable accessor named autoRefreshOnNetworkChange with getter returning the constant false. The setter accepts only primitive false and returns without state change. Every other value throws TypeError synchronously (including true, undefined, null, 0, string, object). Getter/setter do not call caller coercion hooks, access bindings, request accounts, reconnect, sign, send or emit events. Object.isFrozen(provider) MUST stay true: accessor setter compatibility is not permission to alter provider state. Strict attempts to replace/delete request, enable, the accessor, or add an unknown property remain refused. Object.defineProperty cannot replace the accessor. Frozen event methods and discovery behavior remain unchanged.

Add own `async enable(...args)` before freeze. Reject `args.length !== 0` with literal `error.code = -32602` and a fixed non-sensitive message before invoking any binding; this also rejects explicit undefined. No page-side reference to Node-only `CODES`, and no argument coercion. The only successful path returns `provider.request({method:'eth_requestAccounts'})`. Reuse existing request error shaping for valid calls, including code and data. Extracted enable invoked without receiver works because it closes over provider; no use of dynamic this. Do not add enable to the JSON-RPC method allowlist: request({method:'enable'}) remains 4200. No additional origin, frame, chain, account, grant, transaction or signing path. Calls are recorded as eth_requestAccounts, never as an invented enable RPC. Existing control nextRequest({method:'eth_requestAccounts',...}) governs it.

## Verification design
Offline tests must exercise the actual pageScript captured via installForkWallet/addInitScript using existing test fakes (or exact serialized script in VM), not a hand-written compatible object. Bind it to the existing Node request handler to assert enable resolves the owned account only after approval, 4001 rejection, held approval, revoke/reconnect/disconnect errors and no independent grant. Include wrong-frame/origin call rejection and invalid-argument zero-binding controls. For VM realm TypeError use `assert.throws(fn, { name: 'TypeError' })`, not the host TypeError constructor; do not change test/helpers.js. Retain existing unit EIP-6963/freeze assertions.

Add test/legacy-provider.test.js for focused offline cases, included explicitly in package.json `test`; add a separate `test:legacy` script running `node test/run-gate.js test/legacy-compat.test.js`, not another file to the existing `test:sdk` 180s aggregate gate. Use existing test utilities/owned vanilla Anvil/run-gate, two allowed local chains only if needed, random disposable account, no public fork, no fixture private keys, signing disabled. A tiny locally served HTML fixture executes strict false assignment during render using `<script type="module">` or `'use strict'`, then calls provider.enable from a connect action; label it a legacy API fixture, not web3modal/Uniswapper coverage. Confirm account/eth_chainId/read gateway agrees; send one small native transfer on chain31337 under exact from/to/value policy, assert real receipt status1, sender/recipient balance and nonce+1. Test enable rejection with unauthorized state, authorized result, revoke then send denial with unchanged submission count/nonce, invalid assignment/no event and method replacement refusal. Existing SDK/signing regressions preserve broader policies. Service workers and external HTTP/WS blocked; all children/ports verified retired in finally. Missing prerequisites fail without skip. Test wrapper timeout <=180s and per-RPC 15s unchanged.

## Rejected alternatives
- Remove Object.freeze: unnecessarily weakens protected members and discovery contract.
- Proxy permissive property writes or generic mutable bag: unbounded compatibility surface.
- Patch third-party app: stops testing its unchanged source; does not improve reusable product.
- Implement enable as direct RPC/automatic authorization: bypasses existing permission/state machine.
- Expose legacy send/sendAsync or isMetaMask: unsupported by measured need and expands dispatch surface.
- Increase timeouts or use mainnet chain ID: irrelevant to this reproducible synchronous render failure and violates safety boundaries.
